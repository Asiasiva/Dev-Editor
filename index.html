பாதுகாப்பு கட்டுப்பாடுகள் (Sandbox Limits)

பிரவுசரின் கடுமையான பாதுகாப்பு காரணங்களால் Camera, Mic, Geolocation (இருப்பிடம்), LocalStorage போன்ற அம்சங்கள் இந்த உட்பொதிக்கப்பட்ட சிறிய பார்வையில் (Iframe) தடை செய்யப்படலாம்.

எந்தவொரு தடையுமின்றி குறியீடுகள் முழுமையாக இயங்க Open in New Tab பட்டனை அழுத்தவும்!

Some security-sensitive features (Camera, Geolocation) are restricted inside nested sub-frames. Run them natively via Open in New Tab.
